# References

Starting resources for the lab and future implementation:

- [Kali Linux FAQ](https://www.kali.org/faq/) — virtualization and hardware questions.
- [Wireshark wireless capture setup](https://wiki.wireshark.org/capturesetup/wlan) — monitor mode, hardware, and capture limitations.
- [Wireshark sample captures](https://wiki.wireshark.org/SampleCaptures) — documented examples for offline study; check individual terms before redistributing files.
- [RSNA EAPOL-Key field reference](https://www.wireshark.org/docs/dfref/w/wlan_rsna_eapol.html) — message numbers, flags, and nonce fields.
- [TShark manual](https://www.wireshark.org/docs/man-pages/tshark.html) — command-line decoding and field extraction.
- [Four-way handshake walkthrough](https://sharkfest.wireshark.org/retrospective/sfeu/presentations17eu/08.pdf) — packet-level teaching material.

Record tool versions alongside experiments because field availability and behavior can vary by version.
